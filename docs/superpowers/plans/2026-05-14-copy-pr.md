# Copy PR Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a "Copy" button to the EPMS PR list page that creates a new PR pre-populated with all content from the selected PR.

**Architecture:** Pure frontend change — two files only. `PrListPage` gets a checkbox-selection column and a Copy button. `PrCreatePage` reads a `?copyFrom=<pr_id>` URL param, fetches the source PR, and pre-fills all form state once supporting data (vendors, budget, cost centers) has loaded. No backend changes; creation goes through the existing `useCreatePr()` mutation.

**Tech Stack:** React 18, React Router v7 (`useSearchParams`), TanStack Query v5 (`usePr`), React Hook Form + Zod, TypeScript strict.

## Task 2: Pre-fill logic in PrCreatePage

**Files:**
- Modify: `epms/src/pages/pr/PrCreatePage.tsx`

### What changes

1. Read `?copyFrom` URL param with `useSearchParams`.
2. Fetch source PR with `usePr(copyFromId)` — already enabled when id is non-empty.
3. One `useEffect` pre-fills all form state once source PR + vendors + cost centers + budget data are all loaded. Runs once (guarded by `copyFilled` flag).
4. A separate `useEffect` handles vendor matching: once `vendorQuery` is set to the vendor's name, it watches the updated `vendorsData` to find and set `selectedVendor`.
5. Show a blue info banner below the page header when in copy mode: "Copied from PR-XXXX — review all fields before submitting."
6. Change page title to "New Purchase Requisition — Copy of [source number]" when in copy mode.
7. `requiredBy` is intentionally left blank (source date is likely past).

- [ ] **Step 3: Add main pre-fill `useEffect`**

Place this effect after the existing `useEffect` that sets `deliveryAddress` from config (around line 109). It waits for sourcePr, vendorsData, costCentersData, and budgetData to all be loaded before running:

```tsx
useEffect(() => {
  if (!sourcePr || copyFilled) return
  // Wait for supporting data so selects can be set correctly
  if (!vendorsData || !costCentersData || !budgetData) return

  // Procurement type
  setSelectedType(sourcePr.type as ProcurementType)

  // Basic fields
  setValue('title', `Copy of ${sourcePr.title}`)
  setValue('notes', sourcePr.notes ?? '')
  setValue('deliveryAddress', sourcePr.delivery_address ?? config?.delivery_address ?? '')
  setValue('prepaymentRequired', sourcePr.is_prepaid)
  if (sourcePr.project_code) setValue('projectCode', sourcePr.project_code)

  // Currency
  setCurrency(sourcePr.currency as Currency)

  // Line items — assign new local IDs
  if (sourcePr.line_items.length > 0) {
    setLineItems(
      sourcePr.line_items.map((item) => ({
        id: crypto.randomUUID(),
        description: item.description,
        materialId: item.material_id ?? '',
        qty: Number(item.qty),
        unit: item.unit,
        unitPrice: Number(item.unit_price),
        lineTotal: Number(item.line_total),
        notes: item.notes ?? '',
      }))
    )
  }

  // Vendor — set query to trigger search, then match in a separate effect
  if (sourcePr.vendor_id) {
    setCopyVendorId(sourcePr.vendor_id)
    setVendorQuery(sourcePr.vendor_name ?? '')
  }

  // Budget / cost center
  if (sourcePr.cost_center_id) {
    const cc = costCentersData.find((c) => c.id === sourcePr.cost_center_id)
    if (cc) {
      setSelectedCostCenter(cc.code)
      setSelectedCostCenterId(cc.id)

      if (sourcePr.budget_code) {
        setSelectedL2(sourcePr.budget_code)
        // Derive L1 from the account code
        const ccL1 = (budgetData.l1_groups ?? []).filter((l) => l.cost_center_code === cc.code)
        for (const l1 of ccL1) {
          if ((l1.accounts ?? []).some((a) => a.code === sourcePr.budget_code)) {
            setSelectedL1(l1.code)
            setSelectedL1Obj(l1)
            break
          }
        }
      }
    }
  }

  setCopyFilled(true)
// eslint-disable-next-line react-hooks/exhaustive-deps
}, [sourcePr, copyFilled, vendorsData, costCentersData, budgetData])
```

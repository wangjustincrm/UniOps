# features/configuration

Configuration: partners, items, DC routing, connections, settings, notifications — CrudPage screens (FR-OB-09). Built from `@/platform-ui` only (patterns and primitives); no direct `@uniops/shell` import.

- `partners/` (P1, 2026-10-29) — Configuration → Partners on `CrudPage`: list with search / sort, form from a zod schema mirroring the API's DTO (FR-OB-33 included; the server's refusals appear on their field), read-only view for readers without `sales.config`, the partner's audit history under the form, CSV export and import with a dry-run preview. Types in `partnersApi.ts` are hand-written mirrors of `sales-api/app/schemas/partners.py` until OpenAPI type generation is set up.
- `carriers/` (2026-11-03) — Configuration → Carriers on `CrudPage` (`sales.config`, audited, CSV): the 945's W27 SCAC, its name, and a tracking link template (`https://…{tracking}…`; the server fills in the URL-encoded number). Every tracking number in Sales (945 card, its line items, Pallets and lots, Lots, the packing list PDF) shows through `TrackingLink`: a copy chip, and an external-link icon opening the carrier's page in a new tab (`rel="noopener noreferrer"`) when its carrier has a template; an unknown carrier gets the copy chip only. No carrier is seeded (FR-OB-09): add carriers on Configuration → Carriers (PRLA = Purolator).
- `connections/` (2026-11-04) — Configuration → Connections on `CrudPage`. Above the list one row of small cards (`ConnectionSummary`): shadow run, automatic runs, warehouse, 997 wait, 810 invoices, each opening its setting in a sheet. `connectionHealth(c)` is THE health (the list's badge, the sheet's fact and Overview). The form groups its fields by section; a field for one kind only has `showWhen` (`alwaysSent` for what the server needs on either kind: port, after read, wait seconds). The Overview is a set-up checklist (`ConnectionChecklist`) with each step's status, next step and button. Turning the shadow run on or off both ask first; on says how many open orders would be marked (`open_orders` on GET /config/shadow, read only).
